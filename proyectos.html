Web

c_notify

Sistema de notificaciones para servidores de FiveM, la plataforma multijugador de GTA V. El script de juego en Lua recibe cada aviso y se lo pasa a una interfaz web hecha con Svelte y TypeScript, que lo muestra con su color, su icono y el tiempo indicado; las notificaciones entran con una animación y se apilan. Lo hice yo, con JaRoLoz como coautor, y aprendí a comunicar el juego con una interfaz web (NUI) y a usar componentes y transiciones de Svelte.

Tecnologías:

  • Svelte
  • TypeScript
  • Lua
  • HTML y CSS

Ver el repositorio de c_notify en GitHub

EcoMap

Proyecto de la carrera, en equipo con tres compañeros, para encontrar las mejores zonas de España donde instalar energías renovables. Recogimos datos de Red Eléctrica, del clima y del catastro, los preparamos con procesos ETL, entrenamos un modelo que valora la viabilidad de cada zona y lo mostramos en una web con el mapa de provincias. Aprendí a repartir el trabajo con Git y a desplegarlo todo con Docker: Elasticsearch, la API en Python y la web en Svelte.

Tecnologías:

  • Python
  • Jupyter
  • Elasticsearch
  • Docker
  • Svelte
  • TypeScript

Análisis de datos

TFG: Predicción temprana de conflictos

Mi Trabajo Fin de Grado del Grado en Matemáticas Aplicadas al Análisis de Datos, entregado en mayo de 2026. A partir de un panel semanal por país con datos de ACLED y de Eurostat, predice si la semana siguiente habrá eventos de violencia política, y de qué tipo, en 45 países europeos, y una web con un mapa muestra el riesgo de cada país. Comparé nueve modelos con validación temporal y aprendí a calibrarlos e interpretarlos: el mejor llegó a un ROC-AUC de 0,89 en test, y una regresión logística bien regularizada rindió tanto como el boosting.

Tecnologías:

  • Python
  • pandas
  • scikit-learn
  • Jupyter
  • Svelte
  • TypeScript
  • Leaflet
  • Three.js

Ver el repositorio del TFG en GitHub

CSVDataLoader

Clase de Python que carga en DataFrames de pandas todos los CSV de una carpeta y los limpia con métodos por defecto: quita columnas vacías y repetidas, normaliza los nombres, elimina filas vacías y duplicadas y convierte las fechas. También resume los valores nulos y dibuja diagramas de Pareto con matplotlib. La hice para trabajar con datos de actuaciones de bomberos y de accidentalidad, y aprendí a escribir código de limpieza reutilizable en lugar de repetirlo en cada análisis.

Tecnologías:

  • Python
  • pandas
  • matplotlib

Cómo trabajo

  1. Analizar: leo el enunciado o lo que pide el cliente hasta el final y lo convierto en requisitos que se puedan comprobar.
  2. Diseñar: antes de escribir código decido el contenido de cada página y qué etiqueta le corresponde a cada bloque.
  3. Programar:
    • Escribo el HTML semántico, con rutas relativas y nombres de archivo en minúsculas.
    • Después añado el CSS y, si hace falta, el JavaScript.
  4. Probar:
    • Paso cada página por validator.w3.org hasta tener 0 errores.
    • Reviso la jerarquía de encabezados con HeadingsMap.
    • Abro la web con Live Server y compruebo que funcionan todos los enlaces y se ven todas las imágenes.
  5. Entregar: comprimo la carpeta completa y compruebo que la web se ve igual en otro ordenador.
