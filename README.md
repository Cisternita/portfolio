# Portfolio de Alejandro Majado Martínez

Mi portfolio personal, hecho en HTML5 semántico para la asignatura Desarrollo de Web y de Apps de la Universidad
Europea.

URL pública: https://cisternita.github.io/portfolio/

## Páginas

| Página | Qué contiene |
| --- | --- |
| `index.html` | Portada: quién soy, mis habilidades, mi formación, tres proyectos destacados y mi disponibilidad. |
| `proyectos.html` | Mis seis proyectos por categoría (web, programación y análisis de datos), cómo trabajo y una tabla resumen. |
| `contacto.html` | Formulario de contacto accesible con validación nativa de HTML5. |
| `sobre-mi.html` | Mi trayectoria, una línea de tiempo, una demo en vídeo, preguntas frecuentes y mi nivel en tres tecnologías. |

## Vídeo

La demo de `sobre-mi.html` (`media/c-notify-demo.webm` y `media/c-notify-demo.mp4`) es una grabación de mi propio
proyecto, [c_notify](https://github.com/Cisternita/c_notify), con subtítulos en WebVTT (`media/c-notify-demo.vtt`).
